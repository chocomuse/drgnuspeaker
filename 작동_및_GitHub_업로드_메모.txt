Drgnu Jetson Speaker 작동 및 GitHub 업로드 메모
작성일: 2026-06-10

1. GitHub 저장소

- 원격 저장소: https://github.com/chocomuse/drgnuspeaker.git
- 현재 브랜치: main
- 업로드 대상: Jetson AI Speaker Python 클라이언트

2. GitHub에 올리지 않는 로컬 파일

- jetson_speaker/.env
  실제 API 키, 장치 ID, 서버 주소 같은 실행 설정이 들어가는 파일입니다.

- jetson_speaker/.device-token
  페어링 뒤 저장되는 장치 접근 토큰입니다.

- jetson_speaker/.user-info
  앱에서 전달받은 사용자 ID와 이름이 저장되는 파일입니다.

- jetson_speaker/.venv/
  Python 가상환경 폴더입니다.

위 파일들은 로컬 또는 Jetson 장비에서만 사용하고 GitHub에는 올리지 않습니다.

3. 처음 설치할 때

Windows PowerShell 또는 Jetson 터미널에서 아래 순서로 실행합니다.

cd jetson_speaker
python -m venv .venv

Windows:
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env

Jetson Ubuntu:
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

4. .env 설정

jetson_speaker/.env 파일을 열고 최소한 아래 값을 실제 값으로 수정합니다.

DRGNU_BASE_URL=https://aidrgnu.com/
DRGNU_API_KEY=서버에서_발급한_API_KEY
DRGNU_DEVICE_ID=jetson-nano-dev-001
DRGNU_DEVICE_NAME=Drgnu Jetson Speaker
DRGNU_SESSION_ID=test_user_001

중요:
- DRGNU_API_KEY는 GitHub에 올리면 안 됩니다.
- 앱과 로컬 페어링을 사용할 경우 DRGNU_LOCAL_PAIRING_ENABLED=true 상태로 둡니다.
- 실제 음성 호출 전에는 DRGNU_WAKE_MODE=keyboard로 테스트하는 것이 가장 쉽습니다.

5. Windows에서 실행

방법 A: 루트 폴더의 실행 파일 사용

run_speaker.bat

방법 B: 직접 실행

cd jetson_speaker
.venv\Scripts\activate
python -m drgnu_speaker.main

실행 후 Enter 키를 누르면 녹음과 서버 전송 흐름을 테스트할 수 있습니다.

6. Jetson Ubuntu에서 실행

cd jetson_speaker
source .venv/bin/activate
python -m drgnu_speaker.main

마이크, 스피커, 인터넷 연결, .env 설정이 모두 준비되어 있어야 합니다.

7. Jetson 필수 패키지 설치

Jetson에서 오디오와 TTS 관련 패키지가 필요하면 아래 스크립트를 실행합니다.

cd jetson_speaker
chmod +x scripts/install_ubuntu_deps.sh
./scripts/install_ubuntu_deps.sh

8. 앱과 스피커 연결

추천 방식: 같은 Wi-Fi 안에서 로컬 페어링

1. 스피커를 실행합니다.
2. Android 앱에서 Manage -> AI Speaker -> Link AI speaker -> Find nearby speaker 로 이동합니다.
3. 발견된 스피커를 선택합니다.
4. 앱이 사용자 정보를 스피커에 전달합니다.
5. 스피커는 서버에 device_id와 user_id 연결을 요청합니다.
6. 연결 후 jetson_speaker/.user-info 파일이 로컬에 생성될 수 있습니다.

서버에는 아래 API가 필요합니다.

POST /api/devices/link-local

9. 깨우기 모드

개발 테스트:
DRGNU_WAKE_MODE=keyboard

한국어/로마자 호출어 감지:
DRGNU_WAKE_MODE=phrase
DRGNU_WAKE_MODEL_PATH=models/vosk-model-small-ko-0.22

Vosk 한국어 모델 설치:

cd jetson_speaker
./scripts/download_vosk_ko_model.sh

10. 부팅 시 자동 실행

Jetson에서 수동 실행이 정상 작동한 뒤에만 설정합니다.

cd jetson_speaker
chmod +x scripts/install_autostart.sh
./scripts/install_autostart.sh

상태 확인:
sudo systemctl status drgnu-speaker

로그 확인:
journalctl -u drgnu-speaker -f

자동 실행 해제:
chmod +x scripts/uninstall_autostart.sh
./scripts/uninstall_autostart.sh

11. GitHub 업로드 명령

변경 내용 확인:
git status

git add .

12. 업로드 뒤 다른 PC나 Jetson에서 받는 방법

git clone https://github.com/chocomuse/drgnuspeaker.git
cd drgnuspeaker/jetson_speaker
python -m venv .venv

Windows:
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env

Jetson Ubuntu:
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

그 다음 .env를 실제 값으로 수정하고 실행합니다.

13. 자주 확인할 문제

- ModuleNotFoundError:
  가상환경을 켠 뒤 pip install -r requirements.txt를 다시 실행합니다.

- Missing required environment variable:
  .env 파일에 DRGNU_BASE_URL 또는 DRGNU_API_KEY가 빠졌는지 확인합니다.

- 마이크 녹음 실패:
  운영체제에서 마이크 장치가 인식되는지 확인합니다.

- 스피커 소리 없음:
  DRGNU_TTS_COMMAND 설정과 OS 오디오 출력 장치를 확인합니다.

- 앱에서 스피커 검색 안 됨:
  휴대폰과 Jetson이 같은 Wi-Fi에 있는지, 방화벽에서 8765 포트가 막히지 않았는지 확인합니다.
